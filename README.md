## Fastfetch Config

A custom Fastfetch configuration with a PNG image.

# Installation
1. Install Fastfetch.
2. Clone this repository:
bash
> git clone https://github.com/Balaji2217/fastfetch.git

3. Copy config.jsonc to your Fastfetch configuration folder.
4. Store the PNG image wherever you want.
5. Open config.jsonc and change the image path to the location where you saved the PNG.
6. Run Fastfetch:
bash
> fastfetch


That's it! Enjoy your custom Fastfetch setup.
