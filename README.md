## Fastfetch Config

A custom Fastfetch configuration with a PNG image.

# Installation
Install Fastfetch.
Clone this repository:
bash
git clone https://github.com/Balaji2217/fastfetch.git

Copy config.jsonc to your Fastfetch configuration folder.
Store the PNG image wherever you want.
Open config.jsonc and change the image path to the location where you saved the PNG.
Run Fastfetch:
bash
fastfetch


That's it! Enjoy your custom Fastfetch setup.
